Estrutura de Dados em Java OO

Repositório desenvolvido para armazenar exercícios, atividades práticas e resoluções de problemas da disciplina de Estrutura de Dados utilizando Java Orientado a Objetos.

Conteúdos abordados

- Vetores (Arrays)
- Listas sequenciais e encadeadas
- Pilhas
- Filas
- Árvores
- Grafos
- Busca em profundidade (DFS)
- Busca em largura (BFS)

Objetivo

O projeto tem como finalidade apoiar o aprendizado prático das principais estruturas de dados, aplicando conceitos fundamentais da programação e resolução de problemas computacionais em Java OO.

Organização

Os exercícios estão separados conforme os conteúdos e atividades desenvolvidas durante a disciplina.

Requisitos

- Java JDK
- Visual Studio Code (VS Code)

Importante

Este projeto foi estruturado especificamente para execução no VS Code.

Devido à organização das pastas e arquivos do projeto, a execução em outras IDEs pode apresentar problemas relacionados ao reconhecimento de pacotes, caminhos e estrutura das atividades.

Para evitar erros de execução, utilize obrigatoriamente o Visual Studio Code.
